1. **P0 — Lease guards are bypassable.** `ARCHITECTURE.md` §Leases guards selected commands, but `controller/agentvm` runs tools directly over SSH; `connect` checks only when opening a connection. Existing ControlMasters/tunnels survive lease changes, and every registered key reaches every VM. **Fix:** enforce authorization at a host gateway, fence existing connections before reassignment, use lease-generation-specific SSH identities/control paths, and guard lifecycle/snapshot commands too. Separate restricted operational access from unrestricted host/admin SSH.

2. **P0 — `flock` is not a crash-recovery protocol.** §Leases/Profiles lacks an ACQUIRING reservation while freshen/secrets/health run. Reaper, renew, release, and reset completions can race; crashes leave half-created resources. Current `host/agentvm-host` token updates also lose concurrent read-modify-write changes. **Fix:** persist transactional reservations and operation generations before side effects; conditionally commit results, make operations idempotent, reconcile libvirt/storage on startup. SQLite is simpler than coordinating several JSON files.

3. **P0 — Rebuilding backing files can corrupt dependent VMs.** §Profiles promises draining old templates, but `cmd_build_base` calls `upload_vol`, which deletes/recreates the fixed `agentvm-base.qcow2` backing volume. Existing overlays and snapshots still depend on its original contents. **Fix:** immutable, versioned base/template volumes; publish new versions atomically; retain every backing-chain ancestor until all dependent VMs and snapshots disappear.

4. **P0 — “RAM-only” is not a defensible secrecy guarantee.** §Secrets ignores swap, core dumps, application logs, Docker layers, agent transcripts, and a root-capable agent deliberately copying secrets. `controller/agentvm:cmd_prompt` persists prompts/output; current `cmd_snap` captures running memory. **Fix:** describe exposure limits honestly; disable swap/dumps, prevent secret-bearing snapshots, constrain logging, and use short-lived scoped credentials. Disk-only snapshots do not guarantee secret-free disks.

5. **P0 — Proxy tokens authorize much more than inference.** `proxy/agentvm-proxy.mjs:routes` forwards arbitrary methods/paths with host credentials. A guest can invoke Ollama administration, including model deletion/pulls, and access upstream account resources beyond completions. §Security discusses spending but misses shared-service/account exposure. **Fix:** allowlist inference endpoints, methods, providers, and models; reject administration and unrelated account APIs before injecting credentials.

6. **P1 — Snapshot mode needs an explicit implementation contract.** §Profiles offers disk/memory modes, but `cmd_snap` has no mode parameter. Memory restores roll back Docker/Postgres processes and timers while external systems, TCP peers, and clocks continue; disk-only restores require rebooting rather than retaining mismatched RAM. **Fix:** define internal/external snapshot chains, all included disks/volumes, quiescing, reboot behavior, and post-restore health. Prefer cold disposable overlays initially; enable memory snapshots only for tested profiles.

7. **P1 — Expiry, reboot, KEPT, and pets are underspecified.** §Leases permits arbitrary TTLs and caller-chosen holders; wall-clock jumps affect expiry. KEPT can strand capacity and retain dirty secrets indefinitely. Pet ownership is meaningless when laptops share one host account. Autostart can revive dirty expired workloads before reconciliation. **Fix:** authenticated ownership, bounded TTLs, boot-ID/boottime deadlines, conservative reboot fencing, no expired renewals, explicit pet/pool classification, and KEPT quotas, retention, and secret policy.

8. **P1 — Network blast radius exceeds host SSH.** §Security acknowledges host SSH but not guest-to-guest access or other host/LAN/Tailscale services reachable through the NAT host. `cmd_new` applies no isolation or anti-spoofing filter. **Fix:** move host/peer isolation ahead of pooling: deny guest-to-host, guest-to-guest, and sensitive routed destinations except explicit services; add anti-spoofing and resource limits. Document remaining KVM/device attack surface.

9. **P1 — Any guest can repeatedly crash or exhaust the shared proxy.** In `authenticate`, a JWT payload such as `{"avm":{}}` reaches `cred.indexOf` outside the handler’s `try`, causing an unhandled rejection without valid credentials. `requestTimeout=0`, ignored response backpressure, and unlimited socat forks add exhaustion paths. **Fix:** validate credential types, catch the entire request handler, respect backpressure, and bound connections, bodies, durations, concurrency, and spending.

10. **P1 — Tool routing is incomplete and must fail closed.** §Pi extension copies an example routing only read/write/edit/bash; find/grep/ls, MCP tools, other extensions, and user shell commands may remain local. The example also uses unsafe shell quoting and simplistic path replacement. **Fix:** inventory every execution route, implement safe binary transport and explicit path mapping, and reject VM tools on lease loss—never silently fall back to laptop execution.

11. **P1 — Resume cannot restore filesystem state from a lease ID.** §Pi extension promises reacquisition, but normal shutdown releases/reset the VM; expiry can destroy its state, and forks/clones can duplicate stored lease IDs. Reload/session replacement also trigger shutdown. **Fix:** persist VM UUID, template generation, workspace identity, and attachment intent; revalidate host-side ownership/state before routing tools. Distinguish detach, reset, and keep; require explicit recovery when the workspace vanished.

12. **P1 — Build-token and snapshot identity claims conflict.** §Secrets says build tokens remain host-only without defining a credential broker. Guest builds normally receive them; “scrubbing” misses qcow2 history and logs (`image/base-user-data.yaml` enables shell tracing). Per-VM tokens already persist in seed ISOs, guest disks, and snapshots. **Fix:** isolated builders, scoped brokered credentials, clean artifact export, and explicit token exceptions/rotation.

13. **P2 — Narrow unsupported correctness claims.** `ARCHITECTURE.md` calls Tailscale the only transport, but ordinary SSH works; clock stepping is best-effort; ControlMaster cleanup affects only the invoking laptop. `README.md` conflates snapshot/revert timing. `e2e.sh` tests one forged token, not isolation, and accepts any active desktop service. **Fix:** qualify these claims and add concurrency, cross-VM, expiry, crash-recovery, and secret-retention tests.
